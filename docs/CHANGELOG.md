# Changelog

## 2026-06-15

- 详细排班表横向滚动时只冻结 `日期` 和 `星期` 两列。
- `周次 / 4周周期 / 周类型` 不再固定显示，滚动时会滑走。
- 班次列加宽，滚动后更方便直接对照日期、星期查看 5 个人的排班。

## 2026-06-09

- 合并客服排班信息和企微导出信息，每个客服只维护一张卡片。
- 客服卡片现在包含 `姓名 / 账号 / 部门 / 职务 / 当前角色`。
- 移除重复的客服企微导出卡片，产品运维专员继续单独设置。
- 将“排班计算范围”和“企微导出范围”分离。
- 移除 `排班月份 / 套用整月`，改为直接填写排班开始/结束与企微导出开始/结束。
- 企微模板导出只导出指定日期范围，但轮休仍按完整排班范围计算。
- 将排班范围从“开始日期 + 生成周数”优化为“排班月份 / 开始日期 / 结束日期”。
- 新增 `套用整月`，适配按自然月排班。
- 修正非周一开始时仍按周一套班的问题，现在每天按真实星期几取班型。
- 将排班器整理为可上传 GitHub 的静态项目，入口为 `index.html`。
- 新增项目说明、功能记录、接手文档和状态文档。
- 新增开始同步与收尾同步脚本，方便后续像 `redpoint` 一样持续维护。
- 保留当前排班器功能：客服轮休、产品运维固定班、企微模板导出、职务选项。
- 创建并推送 GitHub 仓库：`https://github.com/Lucifer7012/customer-service-scheduler`。
- 启用 GitHub Pages：`https://lucifer7012.github.io/customer-service-scheduler/`。

# Project Status

最新状态（2026-08-06）：

- 项目名称：客服排班器。
- GitHub 仓库：`https://github.com/Lucifer7012/customer-service-scheduler`。
- 在线页面：`https://lucifer7012.github.io/customer-service-scheduler/`。
- 入口文件：`index.html`。
- 当前形态：纯前端单页工具，可直接本地打开，也可通过 GitHub Pages 发布。
- 当前主要功能：
  - 支持完整排班范围和企微导出范围分离。
  - 支持自定义排班开始日期和排班结束日期。
  - 客服信息和排班角色已合并为一张卡片维护。
  - 客服 1-4 固定顺序为杨洋、廖宇杰、彭泳琪、唐禧雯。
  - 产品运维专员排班显示和导出都放在 4 个客服之后。
  - `周四五休A / 周四五休B` 已在规则区、角色下拉和当前角色说明里写清楚周一到周日班次。
  - 详细排班表横向滚动时固定 `日期` 和 `星期`，中间 3 个周信息列不固定。
  - 企业微信模板第 1 行标题默认水平居中。
  - 企业微信模板不再限制 `A1` 标题内容，避免修改标题或格式时弹出 `请勿修改标题`。
  - 四名海外游戏客服排班。
  - 每四周轮换休周末人员。
  - 产品运维专员固定排班。
  - 可编辑企微导出人员信息。
  - 可导出企业微信自定义排班模板。
- 当前默认人员：
  - 产品运维专员：`产品运维专员-曾培钒Wilson`。
  - 客服 1：`海外游戏客服-杨洋Mia`。
  - 客服 2：`海外游戏客服-廖宇杰Kelly`。
  - 客服 3：`海外游戏客服-彭泳琪Punny`。
  - 客服 4：`海外游戏客服-唐禧雯`。
- 当前注意点：
  - `周四五休A` 的固定班型为周一晚、周二白、周三白、周四休、周五休、周六晚、周日晚。
  - `周四五休B` 的固定班型为周一晚、周二晚、周三晚、周四休、周五休、周六白、周日白。
  - 企业微信模板只保留班次区域数据验证，不再给 `A1` 标题加数据验证。
  - 企微模板第 1 行使用样式 `5` 做浅色加粗居中；第 2 行说明仍使用说明样式。
  - 人员顺序不要改回旧顺序；当前固定为杨洋、廖宇杰、彭泳琪、唐禧雯、产品运维。
  - 详细排班表只冻结 `日期 / 星期` 两列；不要把 `周次 / 4周周期 / 周类型` 重新做成横向固定列。
  - 客服卡片同时承担排班显示和企微导出信息，不再维护第二套客服导出卡片。
  - 产品运维专员仍单独设置，因为它不参与客服轮休。
  - 排班范围用于计算轮休上下文，企微导出范围只控制模板日期列。
  - 例如可以从 `2026-05-11` 排到 `2026-06-30`，但企微模板只导出 `2026-06-01` 到 `2026-06-30`。
  - 周末轮换仍按日历周推进，非周一开头时只截取日期范围内的天数。
  - 企业微信导出使用 `休息 / 白班 / 晚班` 三个班次名。
  - 职务下拉选项为 `选填 / 产品运维专员 / 海外游戏客服`。
  - 后续每次改动都要同步更新 `FEATURE_LOG.md` 和本文件。

验证方式：
